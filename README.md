# tp-boissons

projet de recherche open-source sur la consommation de boissons sucrées et l'IMC.# Enquête sur la consommation



de boissons sucrées et l'IMC



\## Présentation



Ce projet d'étude évalue



l'association entre la



consommation hebdomadaire de



boissons sucrées (canettes de 33 cl) et l'Indice de Masse Corporelle



(IMC) au sein d'une cohorte de jeunes adultes.



\## Organisation du dépôt



\-donnees/donnees\_brutes.csv':



Données de l'enquête (Anonymisées).



protocoles/: Procédures opératoires standardisées.



resultats/`: Synthèses statistiques et graphiques.
